# SignBridge web app: shared contract

A static web app. The camera, the landmark tracker and the sign model all run in the browser. There is no build step and no server-side code: plain ES modules, served as files. Three people build it in parallel; this file is what they agree on.

## What it does

One screen. The camera (or a reference video) shows a person signing. A tracker turns each video frame into body and hand landmarks. When the hands come up and go down again, the frames in between are one sign; the model names it, and the app shows that sign as a large pictogram. The user may not be able to read, so pictures carry the meaning and text is secondary.

Nobody edits a file they do not own. Nobody runs `git add`, `git commit` or any other git command that changes state. Nobody deletes or edits existing files outside `web/` (the one exception: core creates `training/export_web.py`).

## Data shapes

**Canonical frame**: `Float32Array(225)` = 75 points × (x, y, z), row-major. Points 0–32 are MediaPipe pose landmarks, 33–53 the left hand, 54–74 the right hand. `x` and `y` are image-normalised (0..1) in the *unmirrored* camera image. A missing hand is all `NaN`.

**Clip**: `Float32Array[]`, one canonical frame per video frame.

**Features**: `Float32Array(32 * 184)`, row-major `[frame][feature]`.

## Module APIs

```js
// web/lib/landmarks.js
export const POINTS = 75, LEFT_START = 33, RIGHT_START = 54;
export function emptyFrame();                 // Float32Array(225), all NaN
export function handPresent(frame);           // boolean: any finite value in points 33..74
export function fromHolistic({ pose, left, right });
// pose: 33 × {x, y, z} or null; left, right: 21 × {x, y, z} or null. Returns a canonical frame.

// web/lib/features.js
export const FRAMES = 32, WIDTH = 184;
export class NoHandError extends Error {}
export function frameFeatures(frame);         // Float32Array(184)
export function trimToHands(clip);            // clip from first to last frame with a hand; throws NoHandError
export function resample(clip, frames = 32);  // nearest-index sampling
export function clipFeatures(clip);           // Float32Array(32 * 184); throws NoHandError

// web/lib/capture.js
export class SignCapture {
  static START_FRAMES = 3; static END_GAP_FRAMES = 8; static MAX_SECONDS = 4; static MIN_FRAMES = 8;
  recording;                                  // boolean
  push(frame, tSeconds);                      // returns the finished clip once, otherwise null
  reset();
}

// web/lib/model.js
export class DenseModel {
  static async load(manifestUrl);             // reads health_signs.json and the .bin beside it
  labels; threshold; weakLabels;
  predict(features);                          // Float32Array(labels.length) of probabilities
}

// web/lib/recognizer.js
export const OTHER = "OTHER";
export function narrow(probs, labels, allowed, threshold);
// -> { label: string | null, confidence: number, top3: [[label, probability], ...] }
export class Recognizer {
  static async load(manifestUrl = "models/health_signs.json");
  labels;                                     // every label, OTHER included
  predict(clip, allowed);                     // allowed defaults to every sign except OTHER and weak labels
}                                             // a clip with no hand gives { label: null, confidence: 0, top3: [] }

// web/lib/tracker.js
export class Tracker {
  static async create(options);               // loads wasm and model from web/vendor/mediapipe/
  detect(video, timestampMs);                 // -> { frame, pose, left, right }
  close();                                    // frame is canonical; pose/left/right are raw point lists or null
}
```

`pose`, `left` and `right` from `Tracker.detect` are for drawing the skeleton. `left` means the signer's anatomical left hand, as MediaPipe Holistic reports it.

## `web/data/signs.json`

```json
{
  "other": "OTHER",
  "groups": [{ "id": "reason", "icon": "…" }, { "id": "symptom", "icon": "…" }, { "id": "conditions", "icon": "…" }],
  "signs": [{ "code": "DOLOR", "group": "symptom", "icon": "😣", "fr": "Douleur", "ar": "وجيعة", "clip": "clips/DOLOR.mp4", "weak": false }]
}
```

There are 22 signs. `weak: true` marks a sign the model is not trusted on (it is shown, but never proposed).

## Behaviour that must match the Python reference

`Demo/consultation/landmarks.py`, `features.py`, `capture.py`, `numpy_model.py` and `recognizer.py` (function `narrow`) define the behaviour. The JavaScript must give the same numbers: the core owner proves this with fixtures generated from Python.

## Facts already measured

- Model: 22 Spanish Sign Language (SWL-LSE) health signs plus OTHER. Cross-validated accuracy 80.7% over all 23 classes and 93.3% in the top 3; about 91% when choosing inside one group.
- Threshold 0.40. Weak label: `CORAZON`.
- The Python pipeline with MediaPipe legacy Holistic runs at about 10 frames per second on this laptop's CPU.
